## 理論基礎

參考相關理論，不示表非得用上。
- DDD: Domain-Driven Design，領域驅動設計，是一種以業務領域為核心的軟體開發方法論。
- ADR: Architecture Decision Record，維護架構決策記錄。
- User Story: 是軟體工程與敏捷開發中，用來從「使用者角度」簡短描述功能與價值的需求表達方式。語法樣板： “As a (role), I want (function) so that (business value)”。
- TDD: Test-Driven Development，測試驅動開發，是一種軟體開發方法學。俱體面開發步驟「紅燈 → 綠燈 → 重構」。
- BDD: BDD, Behavior-Driven Development，行為驅動開發，是一種以協作為核心的敏捷軟體開發方法。俱體面指示規格(spec)撰寫格式「Given-When-Then」。
- CRC cards: Class-Responsibility-Collaborator cards，類別-職責-合作者卡片，是一種用於物件導向分析與設計（OOAD）的視覺化與腦力激盪工具，團隊通常使用實體索引卡或數位白板，為系統中每個重要類別建立一張卡片，在寫程式前快速梳理物件分工與互動。
